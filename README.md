# Yassine Benmansour Portfolio

A modern student developer portfolio built with Next.js, React, Tailwind CSS, and Framer Motion.

## Features

- Dark premium portfolio layout
- Responsive hero, project, skills, about, and contact sections
- Searchable and filterable project library
- Reusable project cards
- Project detail modal
- Smooth hover and reveal animations

## Run Locally

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Edit Projects

Project data is stored in:

```text
data/projects.ts
```

Add, remove, or edit project objects there to update the portfolio.
